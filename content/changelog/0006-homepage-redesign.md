Jev Search accepts requests in any form, but a homepage full of templates suggested the opposite. The new homepage says less and shows more.

- **Three different examples.** A phrase with a source and a time ("Rust async runtimes on Hacker News this month"), a full question with only a source, and a bare topic with neither. None of them is a required format.
- **The routing, previewed.** On desktop, hovering an example lights the engines Jev typically chooses for it under "Search via" and shows the time window it implies.
- **A search box for long questions.** It stays one line at rest and expands when focused, so a long request can be read and edited on a phone. Enter searches.
- **A calmer results header on phones.** Source chips show the icon and result count only, while the progress details still name every source.

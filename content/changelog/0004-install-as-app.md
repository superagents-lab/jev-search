---
title: Install Jev Search as an app
date: 2026-09-19
summary: Jev Search can be installed from the browser on phones and desktops, and on Android you can share text to it to start a search.
---
Jev Search is now a Progressive Web App. Install it from the browser and it opens in its own window, with its own icon, like any other app.

- **iPhone and iPad:** Safari's share menu, then **Add to Home Screen**.
- **Chrome and Edge:** the install icon in the address bar, or **Install app** in the browser menu.
- **Android sharing:** once installed, Jev Search appears in the share sheet. Sharing selected text opens a search for it.

## Still a live search

The app does not cache searches or results. Every search goes to the network. When you are offline, the app shows a page that says so instead of stale results.
